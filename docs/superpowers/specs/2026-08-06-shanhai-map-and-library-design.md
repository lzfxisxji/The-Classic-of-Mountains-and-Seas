# 山海铜盘地图与档案页面设计说明

## 目标

在不重构现有原生 HTML、CSS、JavaScript 项目的前提下，将首页的“山海观测·星图地图”升级为更具数字博物馆气质的探索入口；新增与首页一致的“卷册库”和“图鉴详情”页面。

## 现有边界

- 保留 `index.html` 中的异兽数据展示、档案卡片、弹窗与音效入口。
- 保留地图按钮的 `data-beast` 绑定，继续由既有异兽切换逻辑驱动。
- 地图的“查看档案索引”继续定位到首页档案卡片区域。
- 不引入框架或大型依赖；继续使用原生 ES modules 和现有 `js/data.js`。
- 仅重做地图局部结构、相关样式及必要的事件增强，不修改 Hero 与异兽卡片的内容结构。

## 首页地图：山海铜盘·经纬观测台

### 视觉构成

1. **古卷地形底图**：以深褐纸纹、角标、金色经纬线形成矩形观测台，不使用现实地理边界。
2. **天文铜盘**：地图中心为三层同心铜环，依次表达“山经、海经、荒经”；只作低频呼吸与缓慢偏转，避免持续强旋转干扰阅读。
3. **山海地形**：以原创 SVG 金线绘制抽象山势、海岸、河流、云气与航线，作为铜盘内的探索线索。
4. **观测点**：四个现有异兽按钮被设计为可点击的封印节点，并保留当前的四兽绑定：
   - 01 南山·赤水：赤羽应龙
   - 02 北山·灵泽：白泽
   - 03 东海·发鸠：精卫
   - 04 西山·流波：夔牛

### 交互状态

- **初始**：当前异兽对应节点处于“已锁定”状态，铜盘和地形有轻微环境动画。
- **悬停 / 键盘聚焦**：显示节点名称、档案编号和从中央指向节点的细金线轨迹；不得遮挡其他节点。
- **点击 / Enter / Space**：调用既有异兽切换，更新首页主展示与右侧观测案台；节点变为红色印记并播放一次短促封印扩散动画。
- **查看档案索引**：平滑滚动到现有档案卡片，不新增第二套档案数据。

### 观测案台

右侧信息区改为分层抽拉的档案案台，展示状态、地域、异兽名称、档案等级和要素。点击节点后按“状态条 → 名称 → 数据行”的顺序淡入，但文本内容继续读自现有 `beasts` 数据对象。该区不替代现有弹窗。

### 可访问性与性能

- 所有观测点使用 `<button>`，具有可读标签、焦点样式和键盘操作。
- 通过 `prefers-reduced-motion` 关闭铜盘转动、轨迹扩散与案台进场过渡。
- 地形线条使用内嵌原创 SVG；不加载地图 SDK、视频或大体积纹理。
- 移动端改为“地图在上、观测案台在下”，保持四个点的最小可点击面积。

## 新页面一：卷册库

文件名：`volumes.html`。

卷册库是首页档案的分类入口，使用“书脊 / 卷签”式筛选器，首期提供山经、海经、大荒经、异闻四类。筛选不改变数据来源：页面继续导入 `js/data.js`，以异兽数据中的出处或分类字段生成卡片。卡片显示缩略原画、编号、名称、地域和打开详情的链接。

默认展示全部卷册；筛选通过 URL 查询参数保留状态，例如 `volumes.html?volume=mountains`，因此刷新和分享链接仍可复现当前浏览结果。

## 新页面二：图鉴详情

文件名：`specimen.html`。

详情页接收 `id` 查询参数，例如 `specimen.html?id=yinglong`。页面从 `js/data.js` 查找条目，展示原画、编号、封印、出处、地域、等级、要素、描述以及返回卷册库与首页地图的链接。无效或缺失 `id` 时显示站内风格的“档案未检索到”状态，并提供回到卷册库的按钮；不产生控制台异常。

首页地图和档案卡片在后续实现中可增加“打开图鉴详情”的深链，但保留现有弹窗作为快速预览。

## 文件职责

- `index.html`：仅替换地图区内部标记与链接目标。
- `css/sections.css`：地图的铜盘、地形、观测案台与响应式布局样式。
- `js/app.js`：保持既有 `setSpecimen` 流程，在必要处同步地图节点和案台状态。
- `volumes.html`、`specimen.html`：两张新页面的语义结构。
- `css/library.css`、`css/specimen.css`：分别存放卷册库与详情页样式，复用 `tokens.css`、`base.css`、`components.css`。
- `js/library.js`、`js/specimen.js`：各页面读取 URL 参数与 `js/data.js` 的小型渲染逻辑。

## 验收标准

1. 首页四个地图节点均能切换对应异兽，右侧案台同步变化，原有卡片与弹窗可继续使用。
2. 地图在桌面与移动端没有节点遮挡或无法点击的问题，键盘可操作。
3. 卷册库可筛选、可通过 URL 保持筛选状态，并可打开每个详情页。
4. 详情页可根据四个有效 `id` 呈现相应档案；无效 `id` 有清晰回退状态。
5. 所有图片均来自项目内的原创素材；不引入第三方受版权限制地图、美术或音频。

## 验证方式

- 静态检查 HTML 和 JavaScript 语法。
- 在本地 HTTP 服务下逐一验证四个地图节点、卡片、弹窗、卷册筛选和详情深链。
- 检查窄屏布局与 `prefers-reduced-motion` 状态。
